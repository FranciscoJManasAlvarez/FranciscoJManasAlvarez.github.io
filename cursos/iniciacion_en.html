Introduction to Robotics with ROS 2

First course of the ROS 2 Continuing Education program. It starts from scratch and covers, across five topics, the fundamentals needed to build, debug, simulate and monitor a complete robotic system with ROS 2, using the same autonomous delivery robot (RobotDelivery) as the common thread for all practical exercises.

Practice repository on GitHub

Syllabus

Course structure

TopicTitlePractical content
1Installing ROS 2Work environment and first steps (exercise in preparation)
2ROS 2 fundamentalsNodes, topics, services, actions and custom messages — building the delivery robot
3Documentation, traceability and debuggingGitHub, licenses, TF and recording/playback with rosbag
4Modeling and simulationURDF/XACRO, RViz2 and Gazebo simulation with a LIDAR sensor
5Monitoring and user interfacesRQT, RViz2, Foxglove and a custom PyQt interface

Verifiable practice

Validation and demo repository

The ros2-iniciacion-uned repository contains the automatic exercise-validation package (with a ROS 2 launcher per exercise) and example/demo packages for each topic. It is a living repository: I will keep expanding its documentation and content throughout the course.

The Topic 1 exercise is still to be defined; the rest of the topics (2 to 5) already have complete automatic validation in the repository.
